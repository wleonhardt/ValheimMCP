## Contradicts or bugs

- Goals.Save writes with plain `File.WriteAllText` (also `no_food_acked`, run checkpoints, `vh.orders`, decide policy), but `Goals.All` returns an empty list when the file cannot be parsed, so a torn write loses every goal at the next `Add` (certain, by reading; his holds file does use a temp file).
- `Events.Retired` recognises a dropped main-thread call by matching its message text, which breaks silently if the message changes (certain). Ours throws a typed `ExtensionReloadedException`, which is better.
- `Events.Write` rolls the file when `fi.Length + text.Length > RotateBytes`, comparing bytes with characters (certain; the earlier review already flagged this). `NoteSeen` only prunes texts that never repeated, so a long run of distinct repeating texts grows without bound past 512 (minor, certain).
- `Perf.Due("main_slow")` limits rows per code, not per label, so a second culprit within 50 ms is counted as suppressed and never named (certain, minor).
- `DeadAudit` counts any string literal equal to a member name as a use (all `tools/**/*.ps1` strings too), so it misses dead members that share a common word; good enough as a gate, not as proof (certain).
- `Perf.ThreadCpu` calls kernel32 `GetThreadTimes`: on the Linux dedicated server the DLL lookup fails once and CPU time is dropped, which is handled (`_noCpu`); on Windows it has 15.6 ms grain, so `cpuMs` under about 16 ms is noise (his own note). Not a bug, but do not copy the CPU-versus-wall test for short slices.
- Possible game simplification, fairly sure (about 75 %): his night rules say "sleeping in a bed skips the night" and the night gate treats single player as the skip case; in multiplayer every connected player must be in bed, which his `OthersAwake` fact only partly covers. Nothing to take over except: do not claim a night skip from a single bed in a multi-player `situation`.
- Items marked (friend) above, such as sleep from the afternoon, the 30 s wake cooldown, fire-pit and hearth counting for `CheckFire`, and station range from the player's stand, are his decompile notes. I could not check them against the game DLL here.
